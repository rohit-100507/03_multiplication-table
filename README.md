# Multiplication Table - Python

This is one of my beginner Python projects.

I created this program while learning the **for loop** in Python.
I wanted to practice using a loop in a simple and practical program,
so I created a multiplication table generator.

## What This Program Does

* Takes a number from the user.
* Uses a `for` loop to repeat the calculation 10 times.
* Prints the multiplication table from 1 to 10.

## Python Concepts I Practiced

* `input()`
* `int()`
* `for` loop
* `range()`
* Basic multiplication
* `print()`

## Example

If the user enters:

```text
Enter number: 5
```

The program prints:

```text
------ Table of 5 ------
5 X 1 = 5
5 X 2 = 10
5 X 3 = 15
...
5 X 10 = 50
```

s part of my journey of learning Python.
